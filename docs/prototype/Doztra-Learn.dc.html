const { nom, age } = user;
const [a, ...reste] = liste;
const total = prix ?? 0;
user?.adresse?.ville;

L'opérateur ?? ne remplace que null et undefined, contrairement à || qui remplace aussi 0 et la chaîne vide.

En JavaScript, on stocke une valeur dans une variable. Depuis ES2015, deux mots-clés suffisent : const pour une valeur qui ne sera pas réassignée, et let pour une valeur qui changera.

Astuce
Utilisez const par défaut, et passez à let seulement si vous devez réassigner la variable.
